# ИС «КнигоГрад: Система учёта продаж и поставок»

Веб-приложение для автоматизации торговых и складских процессов сети книжных магазинов ООО «КнигоГрад» (УП 02.01, шифр `УП-02.01-П-7-23-10-26`).

## Стек технологий
- **Backend:** Python, FastAPI, SQLModel, ReportLab
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **СУБД:** SQLite (локальный автономный режим) / PostgreSQL

## Запуск
- Из исходного кода: `Запустить_КнигоГрад.bat` или `python backend/app/main.py`
- Сборка автономного исполняемого файла: `Собрать_EXE_для_флешки.bat`
